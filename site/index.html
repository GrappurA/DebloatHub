DebloatHub

Windows 10/11 debloat, privacy and performance tweaks in one window. Every change is previewable, verified and reversible.

Quickest: one line in PowerShell

Open PowerShell (Start menu, type "PowerShell", Enter), paste this line and press Enter. It downloads the latest release, checks its SHA-256 checksum and starts DebloatHub; click Yes when Windows asks for administrator rights.

irm https://grappura.github.io/DebloatHub/install.ps1 | iex
  1. Nothing is installed: the script is kept in %LOCALAPPDATA%\DebloatHub.
  2. Run the same line again to update.
  3. To remove it, click Remove DebloatHub in the app; it offers to undo its changes first.
  4. Want to read it first? install.ps1 is short.
